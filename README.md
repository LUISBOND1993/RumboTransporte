# RumboApp
RumboApp es una aplicación móvil de transporte desarrollada en **Kotlin** con **Jetpack Compose**, diseñada para conectar a pasajeros con conductores de forma rápida, segura y eficiente. La plataforma permite a los usuarios buscar viajes, visualizar información detallada de conductores y vehículos, y establecer contacto directo vía WhatsApp, todo respaldado por una infraestructura en la nube.

## 🚀 Características Principales
- **Autenticación Segura:** Registro e inicio de sesión mediante **Firebase Authentication** con flujo de recuperación de contraseña por correo electrónico.
- **Base de Datos en Tiempo Real:** Gestión de conductores y viajes disponibles consumidos dinámicamente desde **Cloud Firestore**.
- **Perfil de Usuario:** Personalización de datos del pasajero almacenados de forma persistente.
- **Información Detallada:** Visualización técnica de vehículos (seguridad, marca, modelo) y perfiles de conductores con sistema de calificación.
- **Contacto Directo:** Integración con la API de WhatsApp para comunicación instantánea entre usuario y conductor.
- **UI Moderna:** Interfaz reactiva y fluida construida 100% con **Jetpack Compose** y **Material Design 3**.
